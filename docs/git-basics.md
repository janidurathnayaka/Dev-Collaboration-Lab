
# Git Basics

## Introduction
This document explains the basic Git and GitHub workflow.

## Branches
Branches allow developers to work on changes without affecting the main branch.

## Commits
A commit saves a snapshot of changes in the repository.

## Pull Requests
Pull requests help developers propose, review, and merge changes.

## Learning Goals
- Create and manage branches
- Make meaningful commits
- Open pull requests
- Merge approved changes
